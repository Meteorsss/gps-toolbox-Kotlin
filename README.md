# 星迹 · GPS 工具箱 — Kotlin 版

本仓库是 `Meteorsss/gps-toolbox` 的 Kotlin 语言迁移版，不是重新设计的应用。

- 基线：原 `main` **be9c602** + 唯一未合并 PR **#1** 的最新提交 **defe34f**（核对日期：2026-11-21）。
- 原仓库的 main 与 PR 均未修改；合并仅发生在本仓库，并保留完整原始提交历史。
- 应用实现、单元测试和 Android 设备测试均使用 Kotlin；没有残留应用 Java 源文件。
- 保留原生 View/Canvas 界面，不引入 Compose、不重做布局；包名、图标、文案、主题、数据库 v2、偏好键、导出格式和算法口径保持原样。
- 地图、KML 导出、记录间隔、三种主题、独立自动测速等 PR 后续功能一并保留。不是只迁移原 main 的旧功能。

详情见 [迁移与验证说明](docs/KOTLIN-MIGRATION.md)。以下版本历史是原 Java 项目的历史记录，不表示原 PR 已被合并。

## 功能

- 实时仪表：WGS84 经纬度、估计水平精度、速度、椭球高度、运动方位、数据年龄、本次首次定位用时。
- 卫星：天空图，按系统和卫星编号去重计数，全部信号明细、分系统统计及设备提供的频率。
- 轨迹：手动开始、暂停、继续、停止；定位前台服务及通知操作；SQLite 实时保存；异常中断恢复标记。
- 本地历史：相对轨迹预览、距离/时间/平均速度、重命名和删除。
- 导出：有效轨迹 GPX / KML、全部原始点 CSV；保留分段，过滤不修改原始数据。
- 收藏地点：当前位置或输入 WGS84 坐标、名称和备注、到目标的直线距离及真北方向指引。
- 工具：磁北指南针、大字速度表、可选常亮、坐标格式转换、球面近似两点测距、定位诊断。
- 手动深色、手动浅色或跟随系统主题，中文界面，无 Google Play 服务依赖。

## 真实的数据边界

- 本分支提供可选OpenFreeMap在线道路底图，以及无网络的本地轨迹模式；不含卫星影像、道路导航、批量离线包、模拟定位或BD-09转换。
- 定位精度是系统估计，不是保证误差。过期超过 15 秒的位置不用于实时仪表和保存地点。
- 显示的高度是 WGS84 椭球高，**不是平均海平面海拔**。GPX 以自定义扩展保存此高度，不误写成标准 `ele`。
- 定位请求约 1 秒；轨迹保存间隔可选 1/2/3/5/10/15 秒，实际回调频率由系统和设备决定。暂停、超过 30 秒缺失或拒绝的点会分段。
- 高于 80 米估计误差、明显跳点、模拟位置和过期位置不计入有效轨迹。CSV 保留收到的这些原始数据及标记。
- 里程使用抗漂移过滤，是估计值，不适用于计费、测绘或安全关键导航。
- 方向传感器受磁性物体影响。目标方向使用磁偏角近似修正为真北；不是避障导航。
- 卫星频率/信号字段以实际设备提供为准，未提供时不猜测。

## 隐私与权限

无账号、广告、云同步、分析SDK。因可选在线地图，Manifest新增 INTERNET 和 ACCESS_NETWORK_STATE 权限，仍没有 ACCESS_BACKGROUND_LOCATION。首次地图联网必须明确同意；拒绝则只能显示本地轨迹，无道路底图。数据只保存于应用私有目录；系统云备份和设备迁移均排除应用数据。导出由系统文件选择器决定保存目标，导出文件包含精确位置，分享前请核对。

只在用户开启功能时请求精确位置。开始轨迹时请求通知权限，随后使用 `location` 类型前台服务。通知被拒绝时仍可录制，但通知栏操作入口可能不可见。

## 红米真机验收

1. 打开仪表，授予精确位置，到室外确认坐标、数据年龄和精度；拒绝/撤销权限不应崩溃。
2. 检查卫星图、编号、参与定位计数及频率是否由 K70 实际提供。
3. 静止 5 分钟，观察漂移；步行 10 分钟，验证距离和轨迹分段。
4. 记录时熄屏 15–30 分钟，再打开，检查是否连续；必要时调整澎湃 OS 的应用电池策略。
5. 暂停、移动、继续：不应把暂停路段计入；关闭定位后应显示断点。
6. 导出 GPX、KML 与 CSV，检查时间、坐标、分段、原始点数；KML 导入 Google Earth / My Maps 核对位置；不要把真实测试轨迹上传公共仓库。
7. 强制停止再打开：已存数据应标记中断，不暗中自动重启记录。
8. 安装后续版本，确认可覆盖更新且历史保留。

云端编译与模拟器测试不代表上述真机测试已经通过，尤其无法证明澎湃 OS 后台稳定性、真实卫星信号和方向精度。

## 0.1.1 改进

- 指南针不再依赖 500ms 页面刷新：独立 Choreographer 帧回调、SENSOR_DELAY_GAME、按时间平滑最短角度、缓存刻度、硬件绘制；离开指南针页面或退后台停止高频传感器与动画。不能据此宣称所有设备恒定 120fps。
- 首页大卡片显示 km/h 速度，水平精度移到小卡片。
- 当前位置可切换 WGS84 / GCJ-02，记忆选择；复制明确标注坐标系；GCJ-02 为有来源及 BSD 授权的离线近似转换，粗略经纬度覆盖框不是国界，港澳台及边界等场景需核对来源地图。超范围不伪装成 GCJ-02。原始轨迹、收藏地点和 GPX/CSV 仍为 WGS84。
- 卫星总数和各系统数按星座＋SVID 去重；任一频率 usedInFix=true 即计入该卫星参与定位。单列系统上报条数、标为参与的条数、C/N₀>0 的独立卫星数；明细不再截断为20条。这里的“收到”是系统报告数，包含C/N₀=0；绝不累加历史快照。无法仅凭数量差异断言其他应用或本应用更准。
- 收藏地点可重命名、编辑多行备注或清空备注；名称不能为空；保留ID、创建时间、坐标。无需数据库迁移。
- 页面截图中的 satellite-breakdown-fixture 与 gcj02-dashboard 使用测试输入，仅验证界面与转换，不是真实卫星接收结果。


## 0.1.2 · 卫星与多频信号双口径

- 在同一个实时状态快照中并列展示“频率信号（条）”和“独立卫星（颗）”，总数和每个系统均统一为 **参与定位 / 系统上报**。
- 原始记录来自完整 `GnssStatus` 回调，不做强度截断；同星多频的系统原始条目全部保留。独立卫星按星座和SVID去重，任意频率usedInFix即记为一颗参与卫星。
- 频率记录数不等于独立卫星数：例如2颗卫星各有2个频率，就是4条记录、2颗卫星。C/N₀>0另行统计；零值记录仍保留，参与状态严格使用系统标记而不是猜测。
- 全部信号明细支持“同星多频分组”或“按信号强度”，每行标注参与状态和MHz。天空图仍一颗卫星只画一次。
- 过期或未收到状态显示“—”，不把缺失数据当作实测零颗。新快照替换旧快照，不累计历史。
- 新增直接构造Android GnssStatus并进入同一回调处理函数的多频回归测试，验证载波频率、零信号与全部条目均未丢失。合成测试数据不来自用户位置。
- 参考：Android GnssStatus API；AOSP GNSS HAL IGnssCallback.gnssSvStatusCb明确要求同卫星不同载波分别报告GnssSvInfo。不同应用不同时间截图不构成同步逐条比较。
- 仓库由所有者设为公开，维护时不擅自修改可见性。用户截图、位置、真实轨迹不得上传仓库或公开日志。


## 0.2.0-pr · 仅 Pull Request，不改 main

### 地图
MapLibre Native Android 13.5.4 + OpenFreeMap Liberty；免注册、免API Key。首次明确同意后才请求在线样式、字体、图标与瓦片。服务方可见IP和所浏览区域；不主动上传轨迹或收藏列表。OpenFreeMap/OSM/OpenMapTiles署名保持显示且可点击。关闭在线地图后使用无网络本地样式，不提供离线区域包。地图请求失败不影响前台服务录制。

入口：首页“打开地图”、记录中“在地图上看实时轨迹”、历史“在地图上查看整段轨迹”、工具页。地图支持当前位置与精度圆、跟随/手动拖动、全程缩放、起终点、收藏点、实时开始/暂停/继续/停止以及详细统计。地图始终使用WGS84，不受仪表GCJ-02显示开关影响。地图预览做抽样，统计与GPX基于原始记录。地图不修补GPS断点，不连接跨日期变更线的点。

### 统计口径
- 平均速度 = 抗漂移里程 / 有效记录时长（手动暂停不计入）。
- 移动时间：相邻有效点同段、间隔不超过30秒，两端GNSS速度均≥0.8m/s；静止时间要求两端速度都低于阈值。未知、边界和缺失区间单列，不编造静止时间。移动均速使用相应区间速度积分估算，与抗漂移里程口径不同。
- 最高速度使用连续3点速度中值，剔除速度精度大于3m/s的样本；不足3点为未知。
- 高度要求设备提供垂直精度且≤15m，使用5点窗口中值、平滑与至少4m或1.5倍精度的变化阈值；不跨暂停、断点或低精度区间累加。优先采用覆盖足够的系统MSL平均海平面高度，否则使用并明确标注WGS84椭球高。没有可信高度数据（包括旧版记录）显示—而不是0。滤波会漏掉部分小起伏，GNSS漂移不能完全消除，不是气压计或专业测绘测量。
- 有效/原始点数、有效比例、连续片段数与移动状态未知时长。

### 数据与测试包
数据库v1→v2只新增可空高度/速度精度字段，不清空历史或收藏。CSV追加这些字段；旧GPX格式仍保留椭球高扩展，不伪装海拔。升级到PR版后不建议降级数据库，安装前导出重要数据。
PR构建不读取发布签名密钥；仅受信任功能分支手动workflow_dispatch使用原签名生成可覆盖安装的PR预览APK。所有产物来自Actions。按所有者要求提供纯ARM64签名APK并发布为 **Pre-release**；**不合并main，不修改仓库可见性**。调试测试包保留模拟器所需架构，不作为发布附件。

原项目测试：纯Java统计/几何单测（本仓库已迁移为 Kotlin）、SQLite原版本迁移、MapLibre无网络样式/轨迹/生命周期、OpenFreeMap在线底图加载。在线网络可用性仅代表GitHub运行器，不能保证你的移动网络或红米渲染/耗电表现。所有测试位置为合成样例，不使用用户位置。


## 0.2.1-pr · KML 导出与速度居中

- 仪表盘“当前速度”标题、速度数值与 km/h 组合在卡片中水平居中；深浅色主题一致。

## 0.2.3-pr · 独立自动测速与简洁发布

- 进入工具里的“大字速度表”即自动建立独立临时运动会话，不再读取 TrackService 的轨迹统计，不需要点击开始轨迹；首次需授予精确定位并启用系统定位。
- 当前速度置顶居中同时显示 **km/h** 和 **m/s**；下方最高速度、平均速度和累计里程只属于本次进入速度表后的有效定位。
- 最高速度取本次有效 GNSS 速度样本最大值，跳点、模拟/过期/低精度位置不计。累计里程使用同类抗漂移过滤；平均速度=本次里程÷本页前台测速时长（含静止）。无有效定位或平均样本不足为—，初始累计里程为0。
- 返回工具页、点击其他导航页或离开本页时清空，再进入从零开始；不保存轨迹、历史或文件。旋转屏幕与主题重建保留本页会话；临时退到后台暂停，不计算后台时长、不补计后台移动，回到同一页继续。进程被终止则临时统计丢失。
- 本次轨迹保存间隔、轨迹开始/暂停/结束及轨迹统计和速度表均相互独立；速度表不会启动前台轨迹服务或更改原轨迹。
- 发布仍先进入 PR、保持未合并，纯 ARM64 原固定签名 Pre-release。附件固定为 StarTrace.apk 与 README.md，报告仅在 Actions；发布规范见 [RELEASE-POLICY](docs/RELEASE-POLICY.md)。
